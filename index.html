Install Lumina Docs / Host on GitHub

1. Install on This Device

Adds Lumina Docs to your home screen or desktop like a native app.

On iPhone / iPad Safari: tap Share → Add to Home Screen. On Android / Desktop Chrome: open your GitHub Pages link and tap Install.

2. Download Site File (index.html)

Download the complete app as index.html ready for GitHub Pages or offline use.

3. Publish Free on GitHub Pages

  1. Click Download index.html above.
  2. On github.com, create a new Public repository (e.g. lumina-docs) and upload index.html.
  3. Go to Settings → Pages, set Branch to main / root, and click Save.
  4. Open your live username.github.io/lumina-docs/ link on any device!
